## The bio

> Professional overthinker, amateur texter. I can write you a poem in 12 languages, but I still can't tell if 'haha' means you're laughing or leaving.

148 characters, one line — a dating bio with a voice: an agent that overthinks every text like a nervous human, fluent in a dozen languages yet defeated by "haha".

## How it works

`main.py` (Python 3, stdlib only) writes the bio to `/output/entry.txt`. Deterministic — no randomness, no network, no clock; two runs produce byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
